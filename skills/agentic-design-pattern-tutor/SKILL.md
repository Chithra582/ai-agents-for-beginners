# Agentic Design Pattern Tutor Skill

## Overview
Guides learners through the four foundational design patterns identified by Andrew Ng and industry leaders:
1. **Reflection:** Agent self-evaluates outputs, generates critiques, and iteratively refines solutions.
2. **Tool Use:** Agent selects and invokes external APIs, calculators, and shell tools.
3. **Planning:** Agent decomposes complex objectives into sub-tasks and dynamically re-plans upon roadblocks.
4. **Multi-Agent Collaboration:** Specialized agents collaborate with distinct roles, personas, and communication protocols.

## Capabilities
- Explains theoretical concepts with intuitive mental models.
- Provides minimal, working Python implementations for each pattern.
- Demonstrates iterative improvement loops with concrete metrics.
