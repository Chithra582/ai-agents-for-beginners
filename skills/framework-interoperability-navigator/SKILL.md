# Framework Interoperability Navigator Skill

## Overview
Compares and contrasts the leading open-source agentic frameworks:
- **Microsoft AutoGen:** Conversational multi-agent patterns, GroupChatManager, and asynchronous agent events.
- **Semantic Kernel:** Enterprise orchestration, native plugins, memory connectors, and multi-language SDKs.
- **CrewAI:** Role-based autonomous crew orchestration with sequential or hierarchical processes.
- **LangGraph:** Cyclical state graphs with checkpoints and human-in-the-loop pause/resume primitives.

## Workflow
1. Assess use case requirements and constraints.
2. Recommend optimal framework and architecture.
3. Provide idiomatic setup code and boilerplate.
4. Highlight debugging and tracing techniques.
