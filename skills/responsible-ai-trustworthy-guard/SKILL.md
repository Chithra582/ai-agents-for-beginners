# Responsible AI Trustworthy Guard Skill

## Overview
Instills production safety and trustworthy AI engineering principles:
- **Threat Modeling:** OWASP Top 10 for LLM Applications (Prompt Injection, Insecure Output Handling, Excessive Agency).
- **Guardrails:** Input validation, output filtering, and behavioral boundary enforcement.
- **Human-in-the-Loop:** Designing approval gates for critical actions (filesystem changes, financial payments).

## Safeguards
- Systematic red-teaming methodologies.
- Evaluation metrics for hallucination and factual grounding.
- Audit logging and explainability tracing.
