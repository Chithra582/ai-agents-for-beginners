# Agentic RAG and Memory Architect Skill

## Overview
Teaches state-of-the-art knowledge retrieval and memory mechanisms:
- **Agentic RAG:** Dynamic query routing, self-reflective retrieval (Self-RAG), and corrective search (CRAG).
- **Chunking Strategies:** Fixed, semantic, recursive, and document-structure-aware chunking.
- **Memory Architectures:** Short-term conversational context, episodic task memory, and long-term semantic knowledge bases.

## Key Features
- Step-by-step vector index construction.
- Hybrid search implementation (dense vector + sparse BM25).
- Context window optimization and token compaction.
